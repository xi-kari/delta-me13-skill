**线头 1｜待你定夺：本季度三人八周的优先级怎么排**

推荐（供审议、未采纳）：C 切片——先把看板所需的销售数据迁到新平台，在新平台上做看板，再继续迁其余报表。

- 理由：看板若建在旧系统上，迁移时还得重接或重做，等于给旧系统再添一件要迁走的东西；建在新平台上，它需要的数据本就是迁移的一部分，看板还成了新平台的第一个真实用户，销售会顺带帮着校验数字。
- 代价：看板首版落在 W4–W6，比 B 晚；两条线都押在新平台就绪上；迁移顺序先照顾销售域，未必是旧系统里最紧迫的那部分。
- 反对意见：C 把两件事的风险押在同一个前提上，新平台一卡，两头都停；如果销售眼下最要的是“尽快有东西”，B 的早交付价值可能大于返工成本。
- 改判条件：旧系统有季度内或紧随其后的硬停用日期 → A；销售有早于 W4 的硬性日期，且新平台在 W2 前接不进销售数据 → B，并把返工量登记进计划；看板数据与旧报表系统不同源 → 两件事不抢底座，按人力拆开并行；W1 发现新平台未就绪 → 先补证，暂停本推荐，再在 B 与不行动之间选。
